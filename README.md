# Qpen

Windows のエクスプローラーで選んだファイルを、**Ctrl+Q** で一気に開くツールです。

- PDF と Excel など、**種類の違うファイルを混ぜて選んでもまとめて開けます**（エクスプローラー標準の Enter では開けないケース）
- 15 個を超えても開けます
- Ctrl+Q が効くのは **エクスプローラーが前面にあるときだけ**。ほかのアプリの Ctrl+Q には影響しません
- タスクトレイに常駐し、サインイン時に自動で起動します

## インストール

1. このページの緑の **Code** ボタン → **Download ZIP** でダウンロードして展開
2. 展開したフォルダの **「Qpen をインストール」** をダブルクリック

画面は何も出ません。数秒後に「Qpen をインストールしました」という通知が出れば完了です。失敗したときは、理由を書いたメッセージが表示されます。1 分たっても通知もメッセージも出ないときは、ウイルス対策ソフトに止められている可能性があります。

セキュリティの警告（「Windows によって PC が保護されました」など）が出た場合は、**詳細情報** → **実行**、または **実行** を押してください。インターネットから取得したファイルに出る標準の警告です。

トレイに青い「Q」のアイコンが出ていれば動作中です。インストール後は、ダウンロードしたフォルダを消しても大丈夫です。

### 更新

**自動で更新されます**（v1.2.0 以降）。Qpen は起動した直後に 1 回、GitHub の [Releases](https://github.com/ogura-ryoya/Qpen/releases) を確認します。トレイアイコンを右クリックして **更新を確認** を押すと、いつでも確認できます。新しい版があればダウンロードして入れ替え、「Qpen を v◯◯ に更新しました」と通知します。確認中も Ctrl+Q はそのまま使えます。

起動時の確認に失敗したとき（ネットワークがまだつながっていないときなど）は、1 分後にやり直します（最大 5 回）。5 回とも失敗したときと、**更新を確認** を押して失敗したときは、「更新を確認できませんでした」と通知します。

更新した新しい版が起動できなかったときは、自動で元の版に戻して通知します。その版には自動では更新しません（**更新を確認** を押すと、もう一度試せます）。

v1.1.1 以前を使っている場合や、手動で更新したい場合は、新しい版の ZIP をダウンロードして「Qpen をインストール」をダブルクリックしてください。Qpen が動いていても、自動で止めて上書きし、起動し直します。

## 使い方

1. エクスプローラーで開きたいファイルを選ぶ（Ctrl+クリック / Shift+クリック / Ctrl+A）
2. **Ctrl+Q** を押す

選んだファイルがそれぞれ既定のアプリで開きます。フォルダは無視されます。開けなかったファイルがあると、残りのファイルは開いたうえで、開けなかったファイルの名前を通知します。

### トレイアイコン

- 青い「Q」が出ていれば動作中です。マウスを乗せるとバージョンと使い方が表示されます
- 右クリックするとメニューが出ます。名前・バージョン・使い方が表示され、**更新を確認** で新しい版の確認、**終了（自動起動も解除）** で停止ができます
- 終了後にまた使いたいときは、もう一度インストールしてください（自動起動も元に戻ります）
- PC から完全に消したいときは、終了してから `%LOCALAPPDATA%\Qpen` フォルダを削除してください

## 動作環境

- Windows 10 / 11
- 追加インストール不要（Windows 標準の PowerShell 5.1 で動きます）

## 注意

- 会社の PC などで、管理者のポリシーによって PowerShell スクリプトの実行が禁止されている場合は動きません。
- ウイルス対策ソフトによっては、バックグラウンドで動く PowerShell を警告することがあります。

## 仕組み

- 本体は [Qpen.ps1](Qpen.ps1) 1 ファイルです。`%LOCALAPPDATA%\Qpen` にインストールされます。
- エクスプローラーが前面に来たときだけ Ctrl+Q をホットキーとして登録し、離れると解除します。
- Ctrl+Q が押されたら、前面のエクスプローラー（タブ）で選択中のファイルを `Start-Process` で 1 つずつ開きます。
- 自動起動のため、スタートアップフォルダにショートカット（`Qpen.lnk`）を作ります。登録できなかったときは通知します。
- 自動更新では、GitHub の最新リリースにある `Qpen.ps1` をダウンロードし、中に書かれたバージョンが今より新しければ入れ替えます。構文エラーがないことも確かめます。
- 更新後の新しい版は、起動できたことを `Local\QpenReady` というイベントで前の版に知らせます。60 秒以内に知らせが来なければ、前の版が新しい版を止めて元に戻します。**今後の版でも、この知らせは必ず残してください**（なくすと、更新のたびに元に戻されます）。

## リリースの手順（開発者向け）

1. `Qpen.ps1` の `$Version` を上げる
2. README の「更新履歴」に、同じバージョンの項目（`### X.Y.Z`）を書く
3. main に push する

push すると GitHub Actions（[release.yml](.github/workflows/release.yml)）が `Qpen.ps1` を検証し、`vX.Y.Z` のタグとリリースを自動で作ります。リリースノートには更新履歴の項目が使われます。タグを手で作る必要はありません。`Qpen.ps1` に問題（BOM がない・構文エラー・バージョンが読めない）があるときはリリースされません。
