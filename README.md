# Qpen

Windows のエクスプローラーで選んだファイルを、**Ctrl+Q** でまとめて開くツールです。

- PDF と Excel など、種類の違うファイルを混ぜて選んでも開けます
- Ctrl+Q が効くのはエクスプローラーが前面にあるときだけです。ほかのアプリには影響しません
- タスクトレイに常駐し、サインイン時に自動で起動します

## インストール

1. 緑の **Code** ボタン → **Download ZIP** でダウンロードして展開します
2. 展開したフォルダの **「Qpen をインストール」** をダブルクリックします

「Qpen をインストールしました」と通知が出れば完了です。セキュリティの警告が出たら **実行** を押してください（**詳細情報** と出たら、それを押してから **実行**）。1 分たっても何も出ないときは、ウイルス対策ソフトに止められている可能性があります。

## 使い方

エクスプローラーでファイルを選んで **Ctrl+Q** を押すと、それぞれ既定のアプリで開きます。

トレイの青い「Q」を右クリックすると、バージョンの確認、GitHub を開く、更新の確認、終了ができます。

## 更新

起動時に新しい版を確認し、あれば自動で更新します。更新の内容は [Releases](https://github.com/ogura-ryoya/Qpen/releases) で確認できます。

## アンインストール

トレイの「Q」を右クリックして **終了** を押し、`%LOCALAPPDATA%\Qpen` フォルダを削除してください。

## 動作環境

Windows 10 / 11（追加のインストールは不要です）。会社の PC などで PowerShell スクリプトの実行が禁止されている場合は動きません。

## 開発者向け

`Qpen.ps1` の `$Version` を上げて main に push すると、GitHub Actions が検証してリリースを作ります。リリースノートは前回のリリース以降のコミットメッセージから作られます。
