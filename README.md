# Qpen

Windows のエクスプローラーで選んだファイルを、**Ctrl+Q** でまとめて開くツール。

- PDF と Excel など、種類の違うファイルを混ぜて選んでも開ける
- Ctrl+Q が効くのはエクスプローラーが前面にあるときだけ。ほかのアプリには影響しない
- タスクトレイに常駐し、サインイン時に自動で起動する

## インストール

1. 緑の **Code** ボタン → **Download ZIP** でダウンロードして展開する
2. 展開したフォルダの **「Qpen をインストール」** をダブルクリックする

「Qpen をインストールした」と通知が出れば完了。セキュリティの警告が出たら **実行** を押す（**詳細情報** と出たら、それを押してから **実行**）。1 分たっても何も出ないときは、ウイルス対策ソフトに止められているかもしれない。

## 使い方

エクスプローラーでファイルを選んで **Ctrl+Q** を押すと、それぞれ既定のアプリで開く。

トレイの青い「Q」を右クリックすると、次のことができる。

- バージョンの確認、GitHub を開く、更新の確認
- **ログを開く**：うまく動かないときは、中身を丸ごと開発者に送る
- **終了（自動起動も解除）**：止めて、次のサインインから起動しないようにする。スタートメニューの「Qpen」からまた起動できる
- **アンインストール**：確認のあと、Qpen のファイル・ショートカット・ログをすべて消す

## 更新

起動時に新しい版を確かめ、あれば自動で更新する。更新の内容は [Releases](https://github.com/ogura-ryoya/Qpen/releases) で見られる。

## 動作環境

Windows 10 / 11（追加のインストールは要らない）。会社の PC などで PowerShell スクリプトの実行が禁止されていると動かない。

## 開発者向け

`Qpen.ps1` の `$Version` を上げて main にプッシュすると、GitHub Actions がテスト（`tests/run.ps1`）を動かしてリリースを作る。リリースノートは前のリリースからのコミットメッセージで作られる。
