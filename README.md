# Qpen

Windows のエクスプローラーで選んだファイルを、**Ctrl+Q** で一気に開くツールです。

- PDF と Excel など、**種類の違うファイルを混ぜて選んでもまとめて開けます**（エクスプローラー標準の Enter では開けないケース）
- 15 個を超えても開けます
- Ctrl+Q が効くのは **エクスプローラーが前面にあるときだけ**。ほかのアプリの Ctrl+Q には影響しません
- タスクトレイに常駐し、サインイン時に自動で起動します

## インストール

1. このページの緑の **Code** ボタン → **Download ZIP** でダウンロードして展開
2. 展開したフォルダの **`install.cmd`** をダブルクリック

黒い画面が一瞬だけ出てすぐ閉じます。数秒後に「Qpen をインストールしました」という通知が出れば完了です。

セキュリティの警告（「Windows によって PC が保護されました」など）が出た場合は、**詳細情報** → **実行**、または **実行** を押してください。インターネットから取得したファイルに出る標準の警告です。

トレイに青い「Q」のアイコンが出ていれば動作中です。インストール後は、ダウンロードしたフォルダを消しても大丈夫です。

### 更新

新しい版の ZIP をダウンロードして、同じように `install.cmd` をダブルクリックしてください。Qpen が動いていても、自動で止めて上書きし、起動し直します。

## 使い方

1. エクスプローラーで開きたいファイルを選ぶ（Ctrl+クリック / Shift+クリック / Ctrl+A）
2. **Ctrl+Q** を押す

選んだファイルがそれぞれ既定のアプリで開きます。フォルダは無視されます。

### トレイアイコン

- 青い「Q」が出ていれば動作中です。マウスを乗せるとバージョンと使い方が表示されます
- 右クリックするとメニューが出ます。名前・バージョン・使い方が表示され、**終了（自動起動も解除）** で止められます
- 終了後にまた使いたいときは、もう一度インストールしてください（自動起動も元に戻ります）
- PC から完全に消したいときは、終了してから `%LOCALAPPDATA%\Qpen` フォルダを削除してください

## 動作環境

- Windows 10 / 11
- 追加インストール不要（Windows 標準の PowerShell 5.1 で動きます）

## 注意

- 会社の PC などで、管理者のポリシーによって PowerShell スクリプトの実行が禁止されている場合は動きません。
- ウイルス対策ソフトによっては、バックグラウンドで動く PowerShell を警告することがあります。

## 仕組み

- 本体は [Qpen.ps1](Qpen.ps1) 1 ファイルです。`%LOCALAPPDATA%\Qpen` にインストールされます。
- エクスプローラーが前面に来たときだけ Ctrl+Q をホットキーとして登録し、離れると解除します。
- Ctrl+Q が押されたら、前面のエクスプローラー（タブ）で選択中のファイルを `Start-Process` で 1 つずつ開きます。
- 自動起動のため、スタートアップフォルダにショートカット（`Qpen.lnk`）を作ります。
